# OmniGWAS v0.1.0

## Purpose of this release

Version 0.1.0 establishes a maintainable baseline for OmniGWAS. It identifies the CI-tested surface, makes Python and R maintenance reproducible, hardens the cross-language execution boundary, and documents security and contribution responsibilities.

## Highlights

- Maintained auxiliary CLIs and APIs use fixed R drivers with structured JSON input.
- Cross-language CI checks Python behavior, runnable R sources, and Python-to-R integration.
- Python and R dependencies are locked for development and CI.
- Runtime package installation is removed from maintained R execution paths.
- Security reporting, dependency attribution, contribution, citation, and external-validation policies are documented.
- The SuperGNOVA converter is packaged with a versioned command-line entry point.

## Security changes

Earlier wrapper patterns could place user-controlled values into generated R source and execute predictable temporary R files. Version 0.1.0 separates values from code, executes fixed repository entry points, and includes regression tests for hostile-looking but valid input strings. See [SECURITY.md](../SECURITY.md) for private reporting.

## Tested scope

The release CI covers maintained modules under `analysis/05_auxiliary_tools`, including their Python packaging, runnable R functions, and cross-language bridges. The five top-level analysis category files are research workflow references, not a single sourceable R package. They depend on study-specific inputs, external tools, and scientific assumptions that cannot be validated by generic CI.

easyGWAS is an optional external dependency for selected workflows. It is not bundled in OmniGWAS. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

## Compatibility notes

- Use the repository lock files when reproducing CI or contributing changes.
- Review configured paths, output locations, network use, and optional external tools before running a workflow.
- Do not use private human data in examples, issue reports, or CI fixtures.
- Cite each scientific method and upstream package used by an analysis, not only the OmniGWAS repository.
